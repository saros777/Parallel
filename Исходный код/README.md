# Параллель 5.4.14 — расписание школы

Самостоятельное приложение для Windows 10/11 x64: собственное окно, системные диалоги открытия и сохранения. Основа расписания, недельные исключения, справочники, история и уроки в резерве сохраняются в отдельном файле `.parallel`. Основной режим не запускает браузер и HTTP-сервер.

## Файлы расписаний и таблицы

Меню «Файл»: создать (Ctrl+N), открыть (Ctrl+O), сохранить (Ctrl+S), сохранить как (Ctrl+Shift+S), последние файлы. Новый документ можно создать пустым либо скопировать справочники и нагрузку, оставив карточки в резерве. При открытии другого документа и закрытии окна программа предлагает сохранить изменения. Двойной щелчок по `.parallel` открывает документ в программе.

`.parallel` — сжатый ZIP с `manifest.json` и `state.json`: основа, датированные исключения, справочники и история. JSON и резервные JSON-конверты предыдущих версий открываются; сохранение предлагает новый `.parallel`, не перезаписывая старый JSON. Автокопия для восстановления хранится отдельно от именованного файла. Индикатор различает записанную автокопию и явно сохранённый документ. Более новая автокопия имеет приоритет при восстановлении незавершённой работы.

«Файлы и таблицы» — импорт и экспорт XLSX и CSV: классы, учителя, предметы, кабинеты, подгруппы, нагрузка, основное расписание и выбранная неделя. XLSX может содержать несколько листов. Перед импортом показаны добавления, обновления и ошибки; изменения применяются одной отменяемой операцией. Ссылки сопоставляются по ID или точным названиям. Неизвестный учитель или класс требует исправления таблицы. Доступны пустые шаблоны. Числовые столбцы XLSX остаются числовыми; текст не превращается в исполняемые формулы. CSV — UTF-8 с BOM и разделителем «;»; при чтении также распознаются запятая и табуляция.

Ограничения: таблица до 32 МиБ, до 16 листов, 25 000 строк и 64 столбцов на лист; расписание до 64 МиБ несжатых данных. При запуске рассчитывается видимый диапазон, база передаётся через сжатый IPC, библиотеки PDF/Word загружаются при открытии печати.

## Учителя и формирование карточек

В справочнике учителей слева список с поиском, справа нагрузка выбранного учителя: предмет, класс/подгруппа, число занятий, длина, всего часов, размещено и в резерве. Уроки можно добавлять, копировать, редактировать и удалять. Например, 2 занятия длиной 2 дают 4 часа и две перемещаемые спарки. Дробная нагрузка 0,5/2,5 сохранена: дополнительное занятие проходит через неделю, выбирается I или II неделя.

Рабочие дни и допустимые номера уроков редактируются в матрице. Изменение длины или уменьшение нагрузки не удаляет размещённые уроки молча: для перестройки требуется явный возврат в резерв. Удаление подтверждается и отменяется через историю. Справочники и карточки связаны по ID.

## Сохранённые исправления надёжности

- Один валидатор проверяет файлы и все записи рабочей копии: ссылки справочников, уроки, основу, изменения, отсутствие и резерв. Конфликтующие уроки можно сохранять; текст звонков на занятость не влияет.
- Данные и принадлежность документу записываются одним атомарным обновлением `workspace.json`. При отказе записи открытие/создание не переключает активный документ. Запрос, устаревший после новых правок, отклоняется.
- Ранние запросы второго процесса сохраняются в очереди. Все вызовы нативных диалогов ожидают завершения инициализации. На время файловой команды фоновые элементы редактирования недоступны.
- Старый `project-session.json` читается при миграции. Новая версия хранит сведения о документе в поле `project` рядом с `state` внутри рабочей копии; именованный `.parallel` по-прежнему содержит только расписание.
- Исправлены номера версий, сообщение сборки, обработка старой блокировки. В нативном HTML применяется CSP.

Дополнительный `Parallel-5.4.14-App.zip` содержит EXE приложения и компонент Microsoft для запуска без установки. Распакуйте его полностью. Данные сохраняются в прежней папке пользователя. MSI обеспечивает установку, обновление, ярлыки и ассоциацию `.parallel`; ZIP их не регистрирует.

## Установка

Запустите `Parallel-5.4.14-x64.msi`. Программа устанавливается для текущего пользователя, создаёт ярлыки на рабочем столе и в меню «Пуск». После установки откройте «Параллель».

Приложение использует системный Microsoft Edge WebView2 Runtime. Если компонент уже есть, интернет не нужен. Если его нет, при первом запуске появится предложение установить официальный компонент Microsoft. Установка требует интернета. Перед его запуском приложение сверяет SHA256 и проверяет подпись через API доверия Windows. Изменённый или недоверенный файл не запускается. PowerShell и самораспаковывающийся установщик приложения в этом процессе не используются.

Собственные MSI и EXE не имеют коммерческой цифровой подписи: сертификат издателя не предоставлен. Подпись Microsoft относится только к компоненту WebView2. Отчёт проверки поставляется отдельно; он не гарантирует одинаковое поведение антивируса на всех компьютерах. Отозванный установщик 5.1 не следует запускать или восстанавливать.

## Существующая рабочая база

Перед обновлением закройте старую программу через «Сохранить и выйти» и сохраните резервную JSON-копию. База автоматически открывается из `%LOCALAPPDATA%\ParallelSchool\workspace.json`; не импортируйте начальный файл поверх своей работы. Предыдущие версии базы остаются в подпапке `backups`.

MSI устанавливает программу в `%LOCALAPPDATA%\Programs\ParallelDesktop`. Удаление через «Приложения и возможности» удаляет программу и ярлыки, сохраняя расписание, резервные копии и настройки. Предыдущая установка 5.1 могла находиться в другой папке; её установщик не является частью новой поставки.

## Работа с расписанием

- «Основное расписание» показывает повторяющуюся основу без дат. «По неделям» показывает датированные исключения. Исключение изменяет выбранную неделю, правка основы — соответствующие повторяющиеся уроки.
- Пять учебных дней и все 25 классов исходной базы помещаются в сетку без прокрутки при 1280×720 и 1440×900. Нижняя и правая области изменяют размер; карточки в них фильтруются по всей школе, классу, учителю и предмету.
- Клик по карточке берёт урок, следующий клик размещает его. В режиме классов урок помещается только в строку своего класса. Подсвечиваются заголовки доступных строк и столбцов. Конфликт показывается компактно рядом с указателем; принудительное размещение требует отдельного действия.
- Занятость определяется датой и номером урока. Пустое или скопированное время звонков не создаёт пересечения. Отменённые, снятые и находящиеся в резерве уроки не занимают ячейки.
- В режиме классов карточка показывает предмет, в режиме учителей/кабинетов — класс. «Общее» позволяет настроить поля. Сокращения предметов и показ подгруппы/профиля настраиваются отдельно. Учитель и кабинет остаются частью урока при перемещении.
- Отсутствие учителя снимает затронутые уроки в правую область. Ручной перенос возможен в обе стороны. Основной резерв находится внизу.
- Справочники классов, подгрупп, учителей, кабинетов и предметов редактируются и связаны по идентификаторам. В карточке учителя можно добавлять нагрузку и спарки, в карточке класса — подгруппы.
- Есть история/отмена, JSON-копии, печать, PDF и редактируемый DOCX. Экспорт использует системный диалог сохранения. При ошибке записи окно не закрывается.

## Сборка исходников

Нужны Go 1.26.10 и .NET SDK 8 (только разработчику, для WiX). Все Go-зависимости закреплены в `go.mod`/`go.sum` и включены в `vendor`; WiX 5.0.2 закреплён в `.config/dotnet-tools.json`.

На Windows запустите `СБОРКА.cmd` или:

```powershell
powershell.exe -NoProfile -File build/windows/build.ps1
```

Результат: `dist/Parallel.exe`, официальный `dist/MicrosoftEdgeWebview2Setup.exe` и `dist/Parallel-5.4.14-x64.msi`. При первой подготовке WiX нужен доступ к NuGet. Во время установленного приложения .NET, Go, Node.js и WiX не нужны.

Перекрёстная сборка EXE на Linux: `bash build/windows/build.sh`. MSI собирается на Windows. Ресурс `resource_windows_amd64.syso` уже включён; значок/manifest можно пересоздать утилитой `github.com/akavel/rsrc@v0.10.2`.

## Проверки

`go test -mod=vendor ./...`, `go vet -mod=vendor ./...`, все `node test_*.cjs`. Windows-тесты дополнительно проверяют подпись Microsoft и блокировку установщика компонента от подмены. `qa/studio-browser.cjs` с Playwright/Chromium проверяет реальное взаимодействие с расписанием на временной базе, включая медленную загрузку последнего скрипта интерфейса. Тестовый HTTP-режим существует только для разработки (`--no-browser`).

`qa/windows-install.ps1` предназначен для чистой тестовой Windows: сканирует MSI и EXE активным Defender, устанавливает MSI, запускает установленную программу, проверяет IPC/сохранение/закрытие, восстановление установки и сохранность базы после удаления. Он не предназначен для запуска на рабочем компьютере с существующей базой.

Workflow `.github/workflows/windows-release.yml` публикует MSI, соответствующий архив исходников, SHA256 и отчёт только после успешных проверок. Исходный код приложения сохраняет локальную работу и не передаёт школьную базу в облако. Автоматическая отправка образцов Defender в тесте выключена; антивирус остаётся включённым.

Исходная база содержит ФИО учителей, без персональных данных учеников. Программа не включает сетевую многопользовательскую работу, кадровый учёт и отправку данных в ВШ.
