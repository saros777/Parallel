# Параллель 5.2 — расписание школы

Самостоятельное приложение для Windows 10/11 x64: собственное окно, системные диалоги сохранения, автоматическое сохранение при закрытии. Основа расписания, недельные исключения, справочники, история и уроки в резерве сохраняются в прежнем формате. Основной режим не запускает браузер и HTTP-сервер.

## Установка

Запустите `Parallel-5.2-x64.msi`. Программа устанавливается для текущего пользователя, создаёт ярлыки на рабочем столе и в меню «Пуск». После установки откройте «Параллель».

Приложение использует системный Microsoft Edge WebView2 Runtime. Если компонент уже есть, интернет не нужен. Если его нет, при первом запуске появится предложение установить официальный компонент Microsoft. Установка требует интернета. Перед его запуском приложение сверяет SHA256 и проверяет подпись через API доверия Windows. Изменённый или недоверенный файл не запускается. PowerShell и самораспаковывающийся установщик приложения в этом процессе не используются.

Собственные MSI и EXE не имеют коммерческой цифровой подписи: сертификат издателя не предоставлен. Подпись Microsoft относится только к компоненту WebView2. Отчёт проверки поставляется отдельно; он не гарантирует одинаковое поведение антивируса на всех компьютерах. Отозванный установщик 5.1 не следует запускать или восстанавливать.

## Существующая рабочая база

Перед обновлением закройте старую программу через «Сохранить и выйти» и сохраните резервную JSON-копию. База автоматически открывается из `%LOCALAPPDATA%\ParallelSchool\workspace.json`; не импортируйте начальный файл поверх своей работы. Предыдущие версии базы остаются в подпапке `backups`.

MSI устанавливает программу в `%LOCALAPPDATA%\Programs\ParallelDesktop`. Удаление через «Приложения и возможности» удаляет программу и ярлыки, сохраняя расписание, резервные копии и настройки. Предыдущая установка 5.1 могла находиться в другой папке; её установщик не является частью новой поставки.

## Работа с расписанием

- «Основное расписание» показывает повторяющуюся основу без дат. «По неделям» показывает датированные исключения. Исключение изменяет выбранную неделю, правка основы — соответствующие повторяющиеся уроки.
- Пять учебных дней и все 25 классов исходной базы помещаются в сетку без прокрутки при 1280×720 и 1440×900. Нижняя и правая области изменяют размер; карточки в них сортируются по классу и учителю.
- Клик по карточке берёт урок, следующий клик размещает его. В режиме классов урок помещается только в строку своего класса. Подсвечиваются заголовки доступных строк и столбцов. Конфликт показывается компактно рядом с указателем; принудительное размещение требует отдельного действия.
- Занятость определяется датой и номером урока. Пустое или скопированное время звонков не создаёт пересечения. Отменённые, снятые и находящиеся в резерве уроки не занимают ячейки.
- В режиме классов карточка показывает предмет, в режиме учителей/кабинетов — класс. «Общее» позволяет настроить поля. Сокращения предметов и показ подгруппы/профиля настраиваются отдельно. Учитель и кабинет остаются частью урока при перемещении.
- Отсутствие учителя снимает затронутые уроки в правую область. Ручной перенос возможен в обе стороны. Основной резерв находится внизу.
- Справочники классов, подгрупп, учителей, кабинетов и предметов редактируются и связаны по идентификаторам. В карточке учителя можно добавлять нагрузку и спарки, в карточке класса — подгруппы.
- Есть история/отмена, JSON-копии, печать, PDF и редактируемый DOCX. Экспорт использует системный диалог сохранения. При ошибке записи окно не закрывается.

## Сборка исходников

Нужны Go 1.26.10 и .NET SDK 8 (только разработчику, для WiX). Все Go-зависимости закреплены в `go.mod`/`go.sum` и включены в `vendor`; WiX 5.0.2 закреплён в `.config/dotnet-tools.json`.

На Windows запустите `СБОРКА.cmd` или:

```powershell
powershell.exe -NoProfile -File build/windows/build.ps1
```

Результат: `dist/Parallel.exe`, официальный `dist/MicrosoftEdgeWebview2Setup.exe` и `dist/Parallel-5.2-x64.msi`. При первой подготовке WiX нужен доступ к NuGet. Во время установленного приложения .NET, Go, Node.js и WiX не нужны.

Перекрёстная сборка EXE на Linux: `bash build/windows/build.sh`. MSI собирается на Windows. Ресурс `resource_windows_amd64.syso` уже включён; значок/manifest можно пересоздать утилитой `github.com/akavel/rsrc@v0.10.2`.

## Проверки

`go test -mod=vendor ./...`, `go vet -mod=vendor ./...`, все `node test_*.cjs`. Windows-тесты дополнительно проверяют подпись Microsoft и блокировку установщика компонента от подмены. `qa/studio-browser.cjs` с Playwright/Chromium проверяет реальное взаимодействие с расписанием на временной базе, включая медленную загрузку последнего скрипта интерфейса. Тестовый HTTP-режим существует только для разработки (`--no-browser`).

`qa/windows-install.ps1` предназначен для чистой тестовой Windows: сканирует MSI и EXE активным Defender, устанавливает MSI, запускает установленную программу, проверяет IPC/сохранение/закрытие, восстановление установки и сохранность базы после удаления. Он не предназначен для запуска на рабочем компьютере с существующей базой.

Workflow `.github/workflows/windows-release.yml` публикует MSI, соответствующий архив исходников, SHA256 и отчёт только после успешных проверок. Исходный код приложения сохраняет локальную работу и не передаёт школьную базу в облако. Автоматическая отправка образцов Defender в тесте выключена; антивирус остаётся включённым.

Исходная база содержит ФИО учителей, без персональных данных учеников. Программа не включает сетевую многопользовательскую работу, кадровый учёт и отправку данных в ВШ.
