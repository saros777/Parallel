# Параллель 5.1 — приложение Windows 10/11 x64

Готовая поставка: `Parallel-5.1-Setup.exe`. Установщик создаёт ярлык и запись удаления. Приложение работает в собственном окне Windows (Go + Wails 2.10.2 + системный WebView2), не открывает браузер и не запускает локальный HTTP-сервер. Весь интерфейс, шрифты и библиотеки встроены в EXE. Если WebView2 отсутствует, установщик проверяет подпись Microsoft и устанавливает этот системный компонент; для его первой установки нужен интернет. После установки расписание работает локально без интернета.

## Исправления 5.1

- Занятость вычисляется по дню и номеру урока — тем же координатам, которые показаны в сетке. Текст времени звонка не влияет на свободные ячейки, подбор кабинета и разрешение размещения. Настоящие пересечения одного учителя в одном слоте продолжают отмечаться.
- Подсветка и размещение используют одну проверку. Карточка класса 5а не переносится в строку другого класса. В режимах учителей и кабинетов перенос также сохраняет исходное назначение; изменить учителя или кабинет можно в редакторе.
- Сообщение о конфликте — небольшая панель рядом с указателем без затемнения экрана. Она показывает причину и существующий урок, отмену и явное принудительное размещение.
- Названия в карточках центрированы, размер шрифта подбирается по фактическому тексту и высоте карточки. В режиме учителей и кабинетов карточки показывают классы, а имена учителей и номера кабинетов находятся в заголовках строк.
- Формат рабочей базы прежний. Основа, недельные исключения, справочники, история и резерв сохраняются в `%LOCALAPPDATA%\ParallelSchool`. Удаление приложения не удаляет базу. При обновлении сначала закройте старую версию через «Сохранить и выйти» и сохраните резервную копию.
- Закрытие окна дожидается сохранения; при ошибке записи окно остаётся открытым. Экспорт JSON/PDF/DOCX использует системный диалог сохранения.

## Сборка

Исходники включают закреплённые зависимости в `vendor`, `go.mod`, `go.sum`, значок и Windows manifest. Нужны Go 1.26+ и NSIS 3.x. На Windows запустите `СБОРКА.cmd` или `powershell -NoProfile -File build/windows/build.ps1`. Результаты находятся в `dist/Parallel.exe` и `dist/Parallel-5.1-Setup.exe`. Для перекрёстной сборки на Linux с установленными Go и NSIS: `bash build/windows/build.sh`.

Прямой вызов Go: `CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -mod=vendor -tags desktop,production,wv2runtime.error -trimpath -ldflags="-s -w -H=windowsgui" -o dist/Parallel.exe .`.

Для изменения значка/manifest пересоздайте ресурс: `go run github.com/akavel/rsrc@v0.10.2 -manifest build/windows/app.manifest -ico build/windows/app.ico -o resource_windows_amd64.syso`. Ресурс уже включён в поставку исходников.

Проверки: `go test ./...`, `go vet ./...`, все `test_*.cjs`. `qa/studio-browser.cjs` запускает отдельный сервер исключительно для автоматизированных проверок интерфейса; это не режим работы установленного приложения. Для этой проверки нужен Playwright и Chromium; путь к Chromium можно задать через `CHROMIUM_PATH`.

Подробности проверки и её ограничения — `NATIVE_DESKTOP_QA.md`.

# Параллель 5.0 — рабочее место составителя расписания

Основное расписание показывает повторяющуюся основу без дат, «По неделям» — датированные исключения. Основа первоначально берётся из наиболее полной недели исходной базы; правки повторяются для соответствующих уроков других недель. Недельные исключения имеют приоритет. Новая нагрузка из карточки учителя появляется в резерве основы. Календарные неучебные дни учитываются при повторении.

- Все классы и пять учебных дней помещаются в сетку без прокрутки на 1280×720 и 1440×900. Размер карточек зависит от окна и числа строк; полные сведения — в подсказке и редакторе.
- Клик по уроку берёт карточку, следующий клик размещает. Esc отменяет выбор. Правая кнопка открывает редактор; на пустой ячейке добавляет урок. Конфликт требует явного подтверждения рядом с указателем. В занятой ячейке доступны обмен, резерв и совместное размещение.
- «Классы» показывают предмет, «Учителя» — фамилию с инициалами, «Кабинеты» — номер; «Общее» настраивается в «Виде карточки». Подгруппа и сокращения включаются отдельно. Вся информация остаётся частью одной карточки.
- Нижняя область — резерв. Правая — снятые вручную и из-за отсутствий уроки. Отсутствие учитывает даты и номера уроков. Снятые из-за отсутствия карточки освобождают место в сетке; принудительный возврат требует подтверждения. По умолчанию справа они выровнены по строкам. Обе области сортируются по классу / учителю. Разделители меняют размер мышью или стрелками клавиатуры.
- В справочниках добавляются и редактируются классы, группы, учителя, кабинеты и предметы. В карточке учителя — назначения предметов, часы в неделю и длина блока; спаренные уроки перемещаются вместе. При уменьшении нагрузки уже размещённые занятия не удаляются автоматически.
- Рабочие дни и разрешённые номера уроков учителя проверяются при размещении и подборе замены. Изменения справочников и основы входят в историю и автосохранение. Справочник не синхронизируется с внешней ВШ.

Запуск и сборка: Go 1.26+, внешних Go-модулей нет. `go test ./...`, `go vet ./...`; все проверки логики: `for t in test_*.cjs; do node "$t" || exit; done`.

Браузерная регрессия: при установленном Playwright и Chromium выполните `node qa/studio-browser.cjs /путь/к/linux-бинарнику`. Тест сам запускает отдельный сервер с временной базой, проверяет размеры сетки, размещение, конфликты, резерв, отсутствия, справочники, спарку и повторную загрузку. Рабочая база не используется.

# Параллель 4.0: самостоятельное приложение Windows

## Новое в версии 4.0

Сетка больше не растягивается по ширине окна: 48, 58, 72 или 92 пикселя на слот, одинаково в дне и неделе. Классы остаются строками, дни идут слева направо. На узком экране неделя прокручивается горизонтально. В двух самых компактных вариантах используются короткие обозначения, включая р/я, а/я, м, А, Г, ФК. Пользовательские сокращения имеют приоритет. Цвет карточки зависит от учителя, не от предмета; полные краткие сведения доступны при наведении. Строка и столбец активной ячейки подсвечиваются.

### Перетаскивание и резерв

Выберите «Одна карточка» или «Весь слот». При переносе зелёная рамка обозначает отсутствие новых пересечений, штриховка предупреждает, серый фон защищает другие классы или закреплённые уроки. Окончательная проверка проводится перед применением выбранной операции.

При наложении на карточку можно поменять уроки местами, вытеснить старый урок в резерв или поместить вместе. Если есть пересечения, приложение перечисляет их и предлагает «Игнорировать и разместить» либо отмену. Принудительное размещение не скрывает замечания из контроля; конфликт отмечен красной рамкой. Оно не означает согласования замены администрацией.

Нижняя панель «Неразмещённые карточки» хранит временно убранные уроки. Они не занимают время учителя / класса и кабинет, не участвуют в автоматическом уплотнении и не печатаются. Перетащите карточку обратно в строку её класса. Резерв сохраняется на диске, в резервной копии JSON и в истории. Это не удаление. Закреплённую карточку сначала нужно разблокировать в редакторе. Перемещение в другой класс запрещено, состав профилей редактируется отдельно.

Отменённые уроки не отображаются надписями в сетке. При замене учителя видна только актуальная карточка. История и учёт отсутствий сохраняются; отмену можно вернуть через историю.

### Назначения и кабинеты

При добавлении урока список предметов берётся из учебного плана класса. По предмету и группе подставляется назначенный учитель, при отсутствии прямого назначения используется ближайший исходный урок этого класса. Если достоверного назначения нет, поле остаётся пустым с объяснением. При нескольких назначениях выводится предупреждение; можно выбрать учителя вручную.

В «Кабинетах учителей» задаются правила:

- Жёсткое закрепление: ровно один кабинет; при занятости он остаётся назначенным, а конфликт виден.
- Предпочтения учителя: номера через запятую по убыванию приоритета.
- Предпочтения класса: такой же упорядоченный список.
- Свободный пул: помещения для подбора, если предпочтения заняты.

Приоритет: ручное исключение конкретного урока, жёсткое закрепление, предпочтения учителя, предпочтения класса, свободный пул. Автоматические кабинеты рассчитываются для всего расписания, ручные не перезаписываются. Изменение правил действует на всех датах. Оснащение и вместимость не проверяются.

### Печать

«Печать A4» открывает классы, «Печать по учителям» открывает дневную таблицу учителей. Заголовок листа: только «Расписание дд.мм.гг». Есть необязательная лёгкая заливка по параллелям; по учителям чередуются строки. Учителя выводятся фамилиями с инициалами. Флажки позволяют включать предмет, класс, номер кабинета и дополнительные сведения. PDF сохраняет макет, Word содержит редактируемую таблицу; разбиение в Microsoft Word может отличаться.

В печати по учителям показываются преподаватели с занятиями на выбранную дату; фильтр классов можно применить отдельно. Длинный список делится на страницы, без обрезки. Общие профильные занятия не дублируют строки нагрузки учителя. Отменённые и неразмещённые уроки исключены.

Архив содержит готовый EXE и исходный код. Для обновления завершите прежнюю программу через «Сохранить и выйти», затем запускайте новый EXE. Сохранённая база не заменяется. Проверки и использованные официальные материалы aSc перечислены в `WORKBENCH_QA.md`.

## Новое в версии 3.4

10а: профильные строки сверху вниз СГ и ХБ. 11: СГ, ХБ, ФМ. Профиль определяется по исходному названию группы и уровню предмета; собственные назначения сохраняются в `profileAudience`. 10б остаётся целым классом. Общие уроки не разбиваются. Совместное занятие двух профилей отображается в соответствующих строках, но хранится одной записью и не удваивает нагрузку.

Нажмите урок → «Изменить профили». Можно выбрать один или несколько профилей на конкретную дату. Перетаскивание между строками одного слота предлагает обмен профилями двух отдельных занятий; для общей записи открывает редактор состава. Перенос между разными слотами по-прежнему перемещает блок подгрупп. Изменения подтверждаются, сохраняются автоматически и отменяются через историю. Предмет, учитель, кабинет и время не изменяются. Существующие пересечения не удаляются автоматически. В частности, исходный понедельник, 6-й урок 11 класса содержит пересечение биологии и основ педагогики у СГ; приложение показывает обе записи, а не угадывает, какую удалить.

В предложениях замен только учителя того же или смежного предмета, с проверкой занятости и отсутствий. Точное совпадение выше смежного. Группы смежности: математика / алгебра / геометрия / вероятность и статистика; история / обществознание и их профильные курсы. Для остальных предметов используется точное совпадение. Временная замена не становится подтверждением квалификации. Ручной выбор учителя в полной карточке остаётся доступен диспетчеру.

Автоматический пересчёт следует этим же правилам. Галочку смежности можно отключить, оставив только свой предмет. Допуска посторонних предметов больше нет. Если подходящих кандидатов нет, урок остаётся нерешённым либо отменяется только при выбранной опции отмены.

Порядок профилей одинаков в сетке, печати и Word. Проверки: `node test_profiles_candidates.cjs`; остальные тесты сохранены.

## Исправление 3.3.1

Редактирование только кабинета больше не блокируется существующим пересечением учителя. Короткая форма и полная карточка используют общий механизм: при предупреждениях доступно принудительное сохранение только полей кабинета. Контроль конфликтов сохраняется, остальные поля не обходят проверку. Принудительный выбор записывается в историю и отменяется обычной командой.

Однократная миграция `roomPolicy.assignmentRevision=2` передаёт кабинет 10 Барышниковой Е.А. вместо Валуйских, кабинет 2 Голованеву В.А. вместо Колядиной. Остальные закрепления, включая пользовательские правки, не сбрасываются. Последующие изменения справочника не перезаписываются при перезапуске.

## Новое в версии 3.3

Закрепления 29 кабинетов по предоставленному списку учителей. Автоматический подбор учитывает реальное время занятий; сначала резервирует закреплённые кабинеты, затем свободные для остальных. Ручные назначения имеют приоритет. Оснащение и вместимость помещений не моделируются.

В режиме «День» номер кабинета открывает короткую форму редактирования. Изменение сохраняется автоматически и отменяется через историю. Справочник закреплений доступен кнопкой «Кабинеты учителей». Существующая база мигрирует без замены уроков, учителей, отсутствий или истории; исходные комнаты сохранены в исходных уроках. Производные кабинеты рассчитываются из `preferences.roomPolicy`; исключения сохраняются в `overrides`.

В окне печати доступен редактируемый DOCX, а также прежние PDF и печать. Библиотека docx 9.6.1 включена локально с лицензией; интернет для экспорта не нужен. Разбиение страниц в Word может отличаться от PDF.

Дополнительная проверка: `node test_rooms.cjs`. Инвентаризация проверки: `ROOMS_QA.md`.

## Запуск

Готовому `Параллель.exe` не нужны Go, Python, Node.js или установка дополнительных пакетов. Дважды щелкните EXE: программа запустит свой локальный сервер, доступный только на `127.0.0.1`, и откроет интерфейс в браузере по умолчанию. Интернет для работы не используется.

Программа предназначена для Windows 10/11 x64. Исходное расписание школы включено в EXE; персональные данные учеников не включены. ФИО учителей присутствуют.

## Обновление с предыдущей версии

В работающей программе нажмите «Сохранить и выйти», подтвердите завершение. Распакуйте новый архив и запустите новый `Параллель.exe`. Рабочая база хранится отдельно от программы и будет открыта автоматически. Не удаляйте `%LOCALAPPDATA%\ParallelSchool` и не импортируйте начальный JSON поверх своей работы. Перед обновлением можно скачать резервную копию кнопкой вверху.

## Компактные слоты и печать

Версия 4.0 явно указана в левом верхнем углу и в заголовке окна печати. Если уже работает другая версия, новый EXE предупредит об этом, а не откроет старый интерфейс. Сначала завершите старую программу через «Сохранить и выйти».

В окне печати доступны три готовых варианта:

1. **Книжный · 1 лист**: A4 вертикально, все 25 классов на одном листе, предмет и только номер кабинета, без учителей и длинных названий.
2. **Книжный · крупнее**: до трех листов, отдельно 1–4, 5–9 и 10–11 классы, шрифт 12 пт.
3. **Альбомный · 1 лист**: дополнительный максимально компактный вариант.

По умолчанию печатаются все классы независимо от фильтра на экране. Для ограниченного списка выберите «Только выбранные на экране».

**«Скачать PDF A4»** формирует PDF прямо в приложении без интернета: размер страницы и ориентация фиксированы, окно печати браузера не используется. Такой PDF можно открыть и распечатать в любом просмотрщике. В нем страницы сохранены изображениями высокого разрешения (масштаб 3×, около 288 dpi); текст в PDF не предназначен для поиска или копирования.

Если добавленные подробности не помещаются в макет, печать и PDF блокируются с объяснением. Программа не обрезает последние классы. Выберите крупный макет по ступеням или отключите дополнительные поля.

- По умолчанию в компактном слоте показаны сокращение предмета и только номер кабинета. Два занятия подгрупп располагаются двумя отдельными строками внутри одного слота, три профильных занятия тремя. Данные не объединяются и не удаляются.
- «Вид карточки»: предмет, кабинет, учитель, профиль и сокращения настраиваются отдельно. Клик открывает полные сведения, двойной клик редактирование. Кнопка «Развернуть» возвращает подробные карточки. В недельном виде доступна горизонтальная прокрутка, чтобы текст оставался читаемым.
- «Печать A4» печатает выбранный день и выбранные классы. По умолчанию это книжная A4, поля 5 мм, шрифт 10 пт, предмет и номер кабинета рядом. Обычные школьные дни с 25 классами проверены на одной странице.
- В предпросмотре настраиваются ориентация, поля 3–20 мм, шрифт 9–14 пт, состав полей и показ отмененных занятий. Подгруппы разделены линиями. Настройки печати независимы от вида карточки и сохраняются в рабочей базе.
- Автоподбор уменьшает шрифт не ниже 9 пт. При слишком подробном варианте появляется предупреждение: текст не обрезается и не становится микроскопическим; нужно выбрать подходящий макет перед печатью.
- В системном окне печати оставьте масштаб 100%, бумагу A4 и отключите колонтитулы браузера. Через то же окно можно сохранить PDF. При необходимости увеличьте поля под возможности принтера.
- Номер кабинета берется из начала названия в справочнике: `40 (Кабинет ... №41)` печатается как `40`, без исправления исходного справочника. Если кабинет не назначен или номера нет, показано `—`; выдуманных номеров нет.

## Хранение

- `%LOCALAPPDATA%\ParallelSchool\workspace.json`: текущая база, номер версии и время сохранения.
- `%LOCALAPPDATA%\ParallelSchool\backups`: предыдущие 20 версий.
- `application.log`: технический журнал запуска.
- `session.json`: локальный адрес и временный ключ текущего запуска; никому не отправляйте этот файл.

Изменения записываются через временный файл, синхронизацию и замену основного файла. При конфликте вкладок новая запись отклоняется, а не затирает другую версию. Ошибка записи отображается в интерфейсе. Поврежденная база не заменяется исходными данными автоматически.

В интерфейсе «База и резервные копии» есть открытие папки данных и экспорт/импорт JSON. При восстановлении можно импортировать как обычный экспорт, так и файл из `backups`.

Для остановки локального процесса используйте «Сохранить и выйти». Если закрыть только браузерную вкладку, процесс продолжит работать; повторный запуск EXE откроет уже работающую программу.

## Сборка

Нужен Go 1.26 или новее только на компьютере разработчика. Внешних модулей Go нет, используется стандартная библиотека.

Windows: выполните `СБОРКА.cmd`. Либо:

```bat
set GOOS=windows
set GOARCH=amd64
set CGO_ENABLED=0
go test ./...
go build -trimpath -ldflags="-s -w -H=windowsgui" -o "..\Параллель.exe" .
```

Linux для разработки:

```sh
go test ./...
go run . --no-browser --port 3013 --data-dir ./test-data
```

При запуске без браузера адрес с временным ключом находится в `test-data/session.json`. Параметры предназначены для разработки, обычному пользователю не нужны.

## Структура кода

- `main.go`: встроенные ресурсы, локальный HTTP-сервер, сохранение, резервные копии, проверка доступа и запуск.
- `platform_windows.go`: открытие браузера/папки и сообщение об ошибке Windows.
- `platform_other.go`: поддержка локальной проверки на Linux.
- `ui/engine.js`: проверка пересечений, замен, отсутствий и пересчет дня.
- `ui/app.js`, `ui/dispatcher.js`: интерфейс, редактирование, история и отчеты.
- `ui/compact.js`, `ui/printing.js`, `ui/print-tools.js`, `ui/compact.css`: компактные подгруппы, печатный макет и настройки.
- `ui/html2canvas.min.js`, `ui/jspdf.umd.min.js`: встроенные библиотеки экспорта PDF; лицензии MIT находятся рядом. При обновлении: html2canvas 1.4.1, jsPDF 3.0.4. Подключения к CDN нет.
- `ui/desktop-bridge.js`, `ui/desktop.js`: локальное подключение, сохранение и завершение.
- `ui/*.css`, `ui/fonts/`: оформление и встроенные шрифты; лицензия шрифта приложена.
- `seed.json`: начальное расписание школы. Редактирование seed влияет только на новые рабочие базы после пересборки, не на уже сохраненную базу пользователя.

## Проверки и границы

В проект включены автоматические тесты хранения и правил расписания. EXE не имеет коммерческой цифровой подписи: Windows или антивирус может запросить дополнительную проверку происхождения файла. Не отключайте защиту системы ради запуска.

Проверки разработчика: `go test ./...`, `go vet ./...`, а при установленном Node.js также `node test_engine.cjs`, `node test_dispatcher.cjs` и `node test_print.cjs`. Node.js нужен только для этих тестов, не для приложения или сборки EXE.

Собранный EXE проверен под Wine 10: открытие встроенной базы, добавление отсутствия через интерфейс, запись на диск, обновление страницы, полное завершение процесса, повторный запуск и отмена изменения. Нативная проверка на физическом компьютере с Windows не проводилась. Автоматическое открытие браузера зависит от настроек браузера по умолчанию в Windows.

Приложение не является aSc и не копирует его программный код. Реализованы дневные замены, отмены, частичные отсутствия, перестановки, пересчет дня, история и отчеты. Полный генератор учебного года, кадровый учет, многопользовательская работа по сети и отправка данных в ВШ не входят в эту версию.
