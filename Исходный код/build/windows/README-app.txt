Параллель 5.4.1 — запуск без установки

Распакуйте весь ZIP в одну папку и запустите Parallel.exe.
MicrosoftEdgeWebview2Setup.exe должен оставаться рядом: это официальный
компонент Microsoft, который потребуется только при отсутствии WebView2.
Программа проверяет его хеш и цифровую подпись перед запуском.

Это EXE приложения. Для обычной установки с ярлыками, открытием файлов
.parallel двойным щелчком, обновлением и удалением используйте MSI.

Рабочая копия и резервные версии сохраняются в
%LOCALAPPDATA%\ParallelSchool, а не в папку распаковки.
Свои расписания сохраняйте в отдельные файлы .parallel через меню «Файл».
Перед обновлением закройте старую программу и сохраните копию работы.
