# Проверка версии 5.1

## Исправление занятости

Причина дефекта 5.0: сетка использовала день/номер урока, а пересечения — часы/минуты, включая искусственную подстановку для отсутствующего времени. Проверка переведена на координаты сетки. Добавлены тесты: одинаковое время в разных слотах; разные/пустые времена в одном слоте; перенос в пустой слот без звонка; чужая строка; согласованность подсветки и размещения; реальный конфликт одного учителя с показом класса существующего занятия.

Время остаётся описательным полем и может выводиться в редакторе. Резерв, отменённые и снятые из-за отсутствий уроки не занимают слот. При настоящем пересечении требуется явное подтверждение.

## Нативная оболочка

Go 1.26.10, Wails 2.10.2, системный Microsoft Edge WebView2, NSIS 3.11. Все Go-модули закреплены контрольными суммами и включены в vendor. Режим Windows по умолчанию создаёт самостоятельное окно; интерфейс общается с Go через Wails IPC. API/хранилище вызываются в процессе без TCP-listener. Системный диалог экспорта, автосохранение перед закрытием, защита от закрытия при ошибке записи. Приложение не содержит собственного полного Chromium-дистрибутива, использует общий системный WebView2.

## Выполнено в среде Linux

- Go-тесты хранилища, авторизации, резервных копий и защиты повреждённой базы.
- Тесты нативного IPC: чтение/сохранение/повторное открытие основы и недельных исключений, устаревшая ревизия, закрытие, передача файлов диалогу.
- Все Node-тесты расчётных модулей и нативного транспортного слоя.
- На исходных данных проверены 47 пустых ячеек классов 4б, 5а и 1а: расчёт занятости совпадает с координатами сетки.
- В тестовом Chromium захват карточки занимает около 4 мс; остальные заголовки проверяются по кадрам без блокировки перемещения указателя. Это измерение среды Linux, не результат замера Windows.
- Chromium: размеры 1440×900 и 1280×720 без прокрутки сетки; размещение, запрет чужой строки, компактная панель конфликта, классы в режиме учителей, отмена, резерв, отсутствие/возврат, справочники, спарка, сохранение/перезагрузка.
- Перекрёстная сборка Windows x64 с manifest и значком; сборка установщика NSIS; проверка PE-файлов и целостности архивов/контрольных сумм.

## Ограничения проверки

Реальная Windows и установленный WebView2 в этой среде отсутствуют. Попытка запустить тестовую Windows-среду Wine завершилась ошибкой её системных DLL; она не подтверждает запуск приложения в Windows. Поэтому взаимодействие с реальным Windows WebView2, системными диалогами и первый запуск установщика необходимо проверить на Windows 10/11. Коммерческой подписи у собственного EXE/установщика нет. Подпись Microsoft у устанавливаемого WebView2 проверяется средствами Windows до запуска компонента; при неуспешной проверке установка останавливается.

## Приёмка на Windows

1. Закрыть старую версию, сохранить JSON-копию базы. Установить 5.1 и проверить наличие основы/недельных исключений.
2. Убедиться, что запускается отдельное окно, а не браузер. Проверить большой экран и системный масштаб 125/150%.
3. Переместить карточку в пустой слот того же класса, затем попробовать чужую строку. Проверить настоящий конфликт учителя.
4. Проверить JSON/PDF/DOCX через диалог сохранения; закрытие крестиком после изменения и повторное открытие базы.
5. Удалить приложение: база в LocalAppData должна сохраниться.
