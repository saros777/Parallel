# Проверка версии 5.2

## Сохранённые исправления расписания

Занятость — дата и номер урока, независимо от текста звонков. Отменённые/снятые/резервные уроки не занимают ячейки. Строгое ограничение переноса своей строкой; компактное подтверждение реального конфликта возле курсора; центрированный шрифт; классы в карточках режима учителей; синхронизация режимов, справочники и резерв сохранены. На исходной базе проверяются 47 пустых ячеек классов 4б, 5а и 1а против видимой занятости.

## Изменения поставки

Вместо NSIS — стандартный MSI WiX 5.0.2. В MSI нет собственных скриптов PowerShell и действий запуска устанавливаемого кода. Приложение Go/Wails остаётся самостоятельным окном и использует системный WebView2. При отсутствии компонента пользователь может установить официальный bootstrapper Microsoft; Go сверяет закреплённый SHA256 и Authenticode через WinVerifyTrustEx. Файл удерживается от записи/подмены до завершения установки. Это инженерные изменения установки, а не доказательство причины обнаружения Wacatac в отозванной версии 5.1.

Загрузка базы отложена до DOMContentLoaded, чтобы быстрый ответ IPC не обгонял загрузку обработчиков расписания. Браузерный тест специально задерживает последний скрипт расписания и проверяет готовность актуального интерфейса.

Собственные бинарные файлы не подписаны сертификатом издателя. Отчёт не следует представлять как заключение Microsoft о ложном срабатывании. Установщик 5.1 остаётся отозванным.

## Выполнено локально

Go-тесты и статическая проверка (`go vet`), все Node-тесты, браузерные проверки: 25 строк при 1280×720 и 1440×900, резерв, обмены, реальные конфликты, чужая строка, основа/исключения, отсутствие/возврат, справочники, спарки, сокращения, сохранение/повторное открытие и медленная загрузка скрипта. Перекрёстная компиляция Windows-тестов проверяет типы Windows API; запуск этих тестов требует Windows.

## Проверки конвейера Windows

Windows Server 2022; активный Defender с обновлёнными сигнатурами, без автоматической отправки образцов. Тесты Go, включая проверку цифровой подписи Microsoft и отказ при подмене bootstrapper. Две сборки EXE из одинакового источника должны дать одинаковые байты. MSI отмечается как полученный из интернета и сканируется вместе с EXE. Выполняется установка реального MSI и сверка установленных файлов, сканирование папки установки, запуск установленного окна, IPC/автосохранение/закрытие, отсутствие HTTP-listener, восстановление установки и повторный запуск с маркером в существующей базе, удаление приложения с сохранением базы.

Точный результат, версия Defender, источник сборки и пределы заключения записываются в Parallel-5.2-Verification.json. Только успешная проверка разрешает публикацию соответствующих файлов. Обнаружение угрозы останавливает публикацию.

## Пределы проверки

Это не полноценная проверка всех вариантов Windows 10/11 и их облачной репутационной защиты. Первый сетевой запуск установщика WebView2 при его отсутствии, все драйверы печати, масштабирование мониторов и каждый системный диалог на целевой машине отдельно не покрыты автоматикой. Чистый результат одного Defender не гарантирует результат другого устройства. Подпись Microsoft относится к bootstrapper WebView2, а не к собственному приложению.
