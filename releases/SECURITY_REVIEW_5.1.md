# Состояние проверки установщика 5.1

Установщик отозван после сообщения пользователя: браузер заблокировал скачивание как вирус. На предоставленном пользователем снимке журнала защиты указаны **Trojan:Win32/Wacatac.B!ml**, критический уровень и состояние **«Удалено»**. Затронутый файл — **Parallel-5.1-Setup.exe**; поле `webfile` содержит исходный адрес файла в ветке `codex/parallel-5.1-desktop` этого репозитория. Персональный путь загрузки здесь не публикуется.

`!ml` указывает на обнаружение моделью машинного обучения; это не устанавливает причину и не доказывает ложное срабатывание. До выяснения причины файл не возвращается в выдачу. Не следует восстанавливать файл, разрешать его на устройстве или отключать защиту.

Проверяемый оригинал:

- Файл: Parallel-5.1-Setup.exe
- SHA256: 6b9599b9dbee09f6c0b5f155c69b249d8b23b930e54906a77b3680b65f4222b5
- Размер: 5941718 байт

30 октября 2026 года проверка Windows security gate на Windows Server 2022 завершилась успешно:

https://github.com/saros777/Parallel/actions/runs/41038848204

Workflow проверяет точный SHA256 отозванного файла, обновляет базы Defender, требует работающий антивирус, сканирует оригинал и заново собранный EXE. Также проверяются подпись Microsoft у bootstrapper WebView2, Go-тесты, запуск самостоятельного окна, готовность фронтенда/IPC по сохранённой ревизии базы, отсутствие HTTP-сессии и закрытие окна с сохранением. Автоматическая отправка образцов в этом тесте отключена; защита от вирусов не отключается.

Это не воспроизводит всю конфигурацию устройства пользователя, браузерную проверку скачивания, репутационные и облачные решения. Успех одного окружения не доказывает ложное срабатывание на устройстве пользователя. Причина исходной блокировки остаётся неустановленной. Новая сборка для обхода блокировки не выдавалась.

После получения точного имени обнаружения проверка расширена: сохраняется исходное имя установщика, из точного оригинала без его запуска извлекаются компоненты, проверяются SHA256 оригинальных EXE приложения и Microsoft WebView2, сканируется вся извлечённая папка и проверяется подпись Microsoft у исходного bootstrapper. Любое зарегистрированное Defender обнаружение завершает job ошибкой. Это дополнительная диагностика, а не основание восстановить выдачу установщика.
