# Параллель 5.1 — Windows 10/11 x64

- `Parallel-5.1-Setup.exe` — установщик самостоятельного приложения.
- `Parallel-5.1-Source.zip` — все исходники, закреплённые зависимости и сценарии сборки.
- `Parallel-5.1-SHA256.txt` — контрольные суммы.

Приложение открывается в собственном окне Windows, без браузера и локального HTTP-сервера. Использует Go, Wails и системный WebView2. Для первой установки WebView2 при его отсутствии нужен интернет; далее приложение работает локально.

Перед обновлением закройте старую версию и сохраните JSON-копию базы. Существующая основа и недельные изменения остаются в `%LOCALAPPDATA%\ParallelSchool`.

В 5.1 исправлены расчёт свободных ячеек, зависимость от текста звонков, размер сообщения о конфликте, шрифт и выравнивание карточек, ограничение переноса своей строкой и классы в режиме учителей.

Go/Node/Chromium-проверки пройдены; установщик собран NSIS. Реальный Windows WebView2 в среде разработки недоступен, поэтому запуск окна и установку на Windows следует проверить на целевой машине. Подробный отчёт входит в исходники.
