# Параллель 5.2 — установщик MSI

Новая поставка использует стандартный Windows Installer. Установка приложения не запускает PowerShell и самораспаковывающийся EXE. Сохранены интерфейс, исправления занятости, справочники, основа и недельные исключения. Приложение работает в собственном окне через системный WebView2. При отсутствии компонента предлагается официальный установщик Microsoft; перед запуском проверяются точный SHA256 и Authenticode средствами Windows.

Файлы находятся в ветке `codex/parallel-5.2-files`, папке `releases/5.2`. `Parallel-5.2-x64.msi` — установщик; `Parallel-5.2-Source.zip` — полный проект с зависимостями, конфигурацией CI и сценариями сборки/проверок; `Parallel-5.2-Verification.json` — точный результат Windows-проверки; `Parallel-5.2-SHA256.txt` — контрольные суммы. Коммерческой цифровой подписи собственного приложения нет.

Публикация выполняется после сканирования Defender, проверки реальной установки MSI, запуска установленного окна, IPC/сохранения/закрытия, восстановления установки, сохранности базы при удалении и сканирования исходного архива. Проверка проводится на Windows Server 2022 и не гарантирует одинаковый результат защиты на каждом компьютере. Срабатывание 5.1 не объявлено ложным.

Перед обновлением закройте старую программу и сохраните JSON-копию. Рабочая база остаётся в `%LOCALAPPDATA%\ParallelSchool`; её не следует заменять начальной базой. Само приложение устанавливается в `%LOCALAPPDATA%\Programs\ParallelDesktop`. После установки откройте ярлык «Параллель».

# Установщик 5.1 отозван

На устройстве пользователя Microsoft Defender обнаружил в Parallel-5.1-Setup.exe **Trojan:Win32/Wacatac.B!ml** и удалил файл. Причина пока не установлена. Установщик удалён из текущей ветки выдачи. Не запускайте ранее скачанную копию и не добавляйте её в исключения антивируса. Архив исходников оставлен для проверки, а не как подтверждённая безопасная замена установщику.

# Параллель 5.1 — Windows 10/11 x64

- `Parallel-5.1-Setup.exe` — **отозван, не распространяется до выяснения причины блокировки**.
- `Parallel-5.1-Source.zip` — все исходники, закреплённые зависимости и сценарии сборки.
- `Parallel-5.1-SHA256.txt` — контрольные суммы.

Приложение открывается в собственном окне Windows, без браузера и локального HTTP-сервера. Использует Go, Wails и системный WebView2. Для первой установки WebView2 при его отсутствии нужен интернет; далее приложение работает локально.

Перед обновлением закройте старую версию и сохраните JSON-копию базы. Существующая основа и недельные изменения остаются в `%LOCALAPPDATA%\ParallelSchool`.

В 5.1 исправлены расчёт свободных ячеек, зависимость от текста звонков, размер сообщения о конфликте, шрифт и выравнивание карточек, ограничение переноса своей строкой и классы в режиме учителей.

Go/Node/Chromium-проверки пройдены; установщик собран NSIS. Запуск самостоятельного окна Windows, IPC, сохранение и закрытие дополнительно проверены на Windows Server 2022. Там Defender не воспроизвёл обнаружение исходного установщика; это не отменяет срабатывание на устройстве пользователя. Подробности — в SECURITY_REVIEW_5.1.md. Установщик остаётся отозванным.
