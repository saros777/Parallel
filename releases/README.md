# Параллель 5.0

Скачайте Parallel-5.0.zip кнопкой Download raw file на странице файла и распакуйте архив. Внутри готовое приложение Параллель.exe для Windows x64, инструкция и обновлённые исходники. Перед запуском завершите старую версию через «Сохранить и выйти».

Windows EXE собран перекрёстно. Интерфейс, сохранение, изменения расписания и справочники проверены в Chromium на Linux.
